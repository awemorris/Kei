# BUG-129: Fonts 分類が package menu に無い

Reproduction: reproduced（host、決定的）
Disposition: tracking
Discovery: 2026-10-01、WS106 ws106p002 / q540-i01
Source: 移動前0a43f635のmetadata、移動後313ec26fでも同じ。Linux host / Python3。

## Expected / Observed / Impact

登録された packages/fonts/noto-color-emoji を menu から選べることを期待。
PACKAGE_CATEGORIES に packages/fonts が無いため表示できず、既存の menuconfig host fixture が最初の MAC-T001 で終了する。

## Reproduction / Evidence

`python3 plan/tools/menuconfig-target-host-test.py` → exit1:
`MAC-T001: noto-color-emoji is filed under packages/fonts, which the menu omits`。
移動前の保存rowsを同じ fixture の USER_PROGRAM_ROWS に与え、check_packages() を呼んでも同じエラー。
[移動前 rows](../ws106/programs-before.txt)、[移動前再現](../ws106/menuconfig-baseline.txt)。移動後log: build/ws106-p002/menuconfig-check.log。

## Investigation / Disposition

WS106 の Tests category 追加以前からある別の分類の欠落。今回の移動で対象ID/default/require/installは保持し、個別registry比較はPASS。
類似の [BUG-080](BUG-080.md) は expat/Libraries 欠落を解決済み。Fontsという別条件なのでduplicateや既存修正の取消とはしない。
調査上限: 現在fixtureと移動前rowsの二つの決定的再現、category定義を確認。全fixtureの後続検査はこの失敗で未到達、UI操作は未実施。
WS106は移動に限定するユーザー指示に従い修正しない。修正WS/Phaseは未選定。Bug作成は実装許可ではない。
Next trigger: package/menu整備を選定するとき。Fonts表示とhost fixture全体のPASSを検証する。
WS106のmigration acceptanceをこの無関係な既存欠落で達成したとは扱わず、全fixture PASSも主張しない。

Event: ws106-fonts-tracking。GitHub ticket/comment/index publication deferred。

## 対応（2026-10-03、q643、P1）

`tools/menuconfig.py` の `PACKAGE_CATEGORIES` に「Desktop」（packages/desktop、gtk4）と「Fonts」（packages/fonts、noto-color-emoji）を足した（Fonts の
欠落の後ろに、同じ形の Desktop の欠落もあった）。host fixture の次の検査が gtk4 を「amd64 だけ」で落としたが、desktop の package は desktop と同じく
platform に結び付く（fixture の注釈の BUG-080 の方針）ので、`plan/tools/menuconfig-target-host-test.py` で packages/desktop を platform の検査から外した。
`python3 plan/tools/menuconfig-target-host-test.py` → `MAC-T001 menuconfig round-trip: PASS`（exit 0）。UI の操作（curses の menu で Fonts を選ぶ）は未実施。
handling の WS は未選定（開いている build・menu の WS が無い。Q1 に依頼）。
