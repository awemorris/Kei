# BUG-136: Gears の窓にタイトルバーが出ない

Reproduction: reproduced（ユーザー、5330 実機）
Disposition: resolved（ws099-p023、q609 で直し QEMU で確認。2026-10-03 Q1 が Board を整理）
Discovery: 2026-10-02 user（5330 実機試験の後）「Gearsアプリがウィンドウタイトルバーが出ません。」
Note: Gears は App Home から `/usr/libexec/keiland-x11 /bin/zgears`（X11、zdesktop-x11server の rootless の窓）で起動する。X11 の窓の装飾の経路を調べる。

2026-10-03: Gears（zgears）は user の判断で試験専用になり CI の image から外れた。X11 の窓の装飾の不具合として zterm（X terminal の tile）で再現・確認する。

## 原因と直し（2026-10-02 ws099-p023 / q609-i01、P2、QEMU）

原因: ws114-p007（ユーザーの G05「SSD が要求されないか CSD が要求された場合は Keiland が装飾しない」）の後、zdesktop は SSD を明示的に要求した窓にだけタイトルバーを付ける。X server（`userland/desktop/xserver`）は X の窓を xdg_toplevel にするだけで、SSD を要求していなかった。QEMU の Venus で再現した: 直す前の image では `ZWL DECORATION applied ... mode=1`（CSD）で、`TITLEBAR create` が無い（[PNG](../ws099/phase023/evidence/base-gears-6s.png)）。
直し: X server が X の top-level ごとに、最初の commit の前に keiland_titlebar（Keiland の明示的な SSD の要求）を作る（`wayland.c`、link に libkeiland を追加: `platform/amd64/vmunix.mk`）。直した後は `TITLEBAR create` → `DECORATION applied mode=2` → `MAP` の順になり、Gears にタイトルバーが出る（[PNG](../ws099/phase023/evidence/fix-gears.png)）。同じ原因で Notes と試験の client（popup-probe・wlshm）にもタイトルバーが出ていなかったので、それぞれ同じ形で要求させた。
zterm でも直した image で `TITLEBAR create` → `DECORATION applied mode=2` → `MAP` の順になり、タイトルバーが出た（[PNG](../ws099/phase023/evidence/fix-zterm.png)）。直す前の zterm は流していない。実機（5330）での確認は未実施（ユーザーに依頼する）。

2026-10-03 Q1: ws099-p023 で原因と修正を QEMU で確認（main d5e5cfa6a）。Disposition は 5330 のユーザーの目視の後に resolved にする。
