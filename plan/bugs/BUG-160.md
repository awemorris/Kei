# BUG-160: WiFi の鍵の入力欄が画面の下の方に出る（AP の行の中で入力できない）

Reproduction: reproduced（ユーザーの観察、S1 の実機、2026-10-03）
Disposition: scheduled（P1、q642）
Discovery: 安定版 S1 の後のユーザーのフィードバック

2026-10-03 user「フィードバックですが、WiFiパスワードが画面の下の方になってしまうので、APの項目でインラインで入力できるようにP1でバグとして修正してください。」

鍵の要る AP を選ぶと、鍵の入力欄が一覧の下（画面の下の方）に出て、選んだ AP と離れている。選んだ AP の行の中（直下）に入力欄と Join・Cancel を出す（インライン）。Settings の Wi-Fi の頁と system bar の network の menu の両方で、どちらが該当するかを確かめて直す。QEMU の network-probe（Neighbor 5G は鍵が要る）で確認できる。

## 対応（2026-10-03、q642、P1）

handling: [ws005-p029](../ws005/phase029/phase.md)。該当は system bar の network の menu（鍵の欄が一覧の全部の後、失敗の行は menu の一番下）。欄と失敗の行を
選んだ AP の行の直下に移した。Settings の Wi-Fi は欄が既に AP の直下だったが、下の方の AP では pane の外に出たので、欄が開いた時に頁を scroll して見せる。
build warning 0、host の描画で確認、QEMU は T1 に依頼（結果待ち）。
