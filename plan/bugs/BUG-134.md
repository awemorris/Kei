# BUG-134: AX211 が動作せず、driver を有効にすると起動が止まる

Reproduction: unreproduced（passthrough 4 回・実機 1 回とも起動停止なし）
Disposition: resolved（2026-10-02 ユーザーの実機確認、デモ config の firmware 欠落を ws129-p009 で解消）
Discovery: 2026-10-02 ユーザー「AX211が動作しなくなっています。しかも、ドライバを有効にすると起動も停止してしまいます。PCIパススルーでQEMUを起動してデバッグしておいてほしいです。これは最初に取り組みましょう！」
Owner: P1（q590）

## 期待・観測

- 期待: `CONFIG_DRIVER_PCI_INTEL_AX211 := y` の image が起動し、Intel AX211/CNVio2（`8086:51f0`、subsystem `8086:4090`）で WiFi が使える（ws004-p038 系の以前の到達点）。
- 観測（ユーザー）: AX211 が動かない。driver を有効にすると起動が止まる。既定の `config.mk` では `CONFIG_DRIVER_PCI_INTEL_AX211 := n`。
- 環境: Latitude 5330（host `solaris10-man` = chaos、Linux）。AX211 は `0000:00:14.3`、IOMMU group 11 に単独、host では iwlwifi が bind、`wlp0s20f3` は DOWN。host の network は USB の LAN `enx6c1ff71a08b6`（10.0.10.25）。

## 調査

q590（P1、2026-10-02）の詳細は [phase051](../ws004/phase051/phase.md) の「結果」。要点:

- passthrough（AX211 単独、AX211 + iGPU、demo の config、main の config.mk の写し、12 vCPU）の 4 回とも起動は完了し、AX211 は attach・firmware 起動
  （runtime_active=1）・scan（36 件）まで動いた。gdbstub で全 thread を確かめ、止まっている thread は無かった。
- 「動かない」の一因: demo の image は AX211 driver=y だが `intelax211-firmware` を含まない（`plan/ws035/tests/config-amd64-userland.mk` 由来）。
- 起動停止は passthrough に無い条件（素の 5330）に依存すると推定。候補（未検証）: BAR が xHCI・HDA と同じ 2 MiB に並ぶ配置、IRQ16 の INTx 共有、
  UEFI から直の CNVi の状態。
- 2026-10-02 ユーザー決定（Q1 経由）: ユーザーが実機で切り分けてから再開。実機試験用の image は phase051 に記録。

再調査の契機: ユーザーの実機の結果（止まる画面、kernel message の写真、`dmesg`）。

2026-10-02 / user: 「AX211は実機できちんと動いていた記憶が私にはあります。WSに記録されていなかったかもしれませんが、実機動作済みであることは確かです。」→ 以前は実機で動いていた（記録漏れ）。回帰の可能性が高い。ユーザーがこの後 P1 の image（build/p1-usb）で実機試験する。

## 2026-10-02 / 実機の結果と解決

2026-10-02 user（5330 実機試験の後）:「AX211は実機動作しました。」（P1 の image `build/p1-usb`、CI の `config/ci/config-amd64.mk` 土台＋`intelax211-firmware`、5330 の USB 単独起動）。driver 有効で起動停止は起きず、AX211 が動いた。
原因の判定: 動かなかった image（デモ）は driver=y だが firmware を含まない config だった（q590 の発見）。デモの config は ws129-p009（q594）で CI 土台に変え、firmware が入った。起動停止は passthrough でも実機でも再現しない。
Disposition: resolved（2026-10-02 ユーザーの実機確認、デモ config の firmware 欠落を ws129-p009 で解消）
