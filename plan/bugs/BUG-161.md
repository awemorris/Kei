# BUG-161: 音量の変更のたびに desktop.conf へ書く（変更ごとに I/O が出る）

Reproduction: reproduced（code の読み、2026-10-03）
Disposition: scheduled（ws100-p011、P1）
Discovery: T2-006 の volume-p005 の FAIL（`settings slider: kept in desktop.conf`）の報告を受けたユーザーの判断

2026-10-03 user「音量の変更をいちいちファイルに書くのはおかしいです。I/Oが発生するべきではないです。ログインセッションの終わりに記録する程度でいいはずです。」

## 今の動き（main、2026-10-03）

- zdesktop の system bar（`userland/desktop/wayland/volume.c`）: 変更の 1 秒後（`VOLUME_SAVE_MS`）に preferences（desktop.conf）へ書く。書いた値の読み戻しを見分ける仕組み（`saved*`・`VOLUME_ECHO_MS`、BUG-153 の直し）もある。
- Settings の Sound（`userland/desktop/settings/sound.c`）: slider を離すたびに `sound_save` で desktop.conf へ書く。
- 両者は desktop.conf を介して音量を共有している。

## 求める動き

- session の間の音量は audiod（メモリ）だけが持ち、system bar と Settings は audiod の値を見て合わせる。音量の操作で file に書かない。
- session の終わり（Log Out・Shut Down・Restart）に zdesktop が一度だけ desktop.conf へ書く。次の login で読み、audiod へ適用する。
- 電源の断や crash で session の途中の音量が失われるのは許す（ユーザーの判断の範囲）。
- BUG-153 の読み戻しの仕組みは、file を書かなくなれば不要になるので外す。
- 試験: volume-p004・p005 の「desktop.conf に残る」の項目は「操作中は desktop.conf が変わらない」「Log Out の後に残り、次の login で戻る」に置き換える。
