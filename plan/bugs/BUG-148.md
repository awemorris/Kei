# BUG-148: system bar の WiFi の menu の下端の「Disconnect from ...」が画面の外に切れる

Reproduction: reproduced（P1 / q627、QEMU の Venus、RTL8822BU の passthrough、AP が多い時）
Disposition: resolved（ws005-p030、接続中の AP を一番上に Disconnect の button、画面に収まらない時は弱い AP を減らす。T1-031 の QEMU で確認、実機は S2）
Discovery: ws005-p020 / q627（2026-10-03）。scan の結果が多いと menu の高さが画面を越え、最後の項目が見えない。menu の高さの上限と scroll（または一覧の件数の制限）が要る。

2026-10-03 user（直し方の希望、記録のみ）:「disconnect fromについては、接続中のAPが一番上に表示されて、そこにDisconnectボタンがあるのがいいです。」→ menu の一番上に接続中の AP を出し、その行に Disconnect の button を置く（下端の「Disconnect from ...」の項目は無くす）。

2026-10-03 P1（q627）: 1280x800 の画面で system bar の network の menu の「Disconnect from ...」の項目が下端で切れる（QEMU、build/p1-rtl-shots/）。menu の設計（接続中の AP を上に、Disconnect の button）は既に記録済み。

## 対応（2026-10-03、q643、P1）

handling: [ws005-p030](../ws005/phase030/phase.md)。user の希望どおり、接続中の AP を一覧の最初に置き、その行の右端に Disconnect の button を出した
（下端の「Disconnect from X」の行は無くした）。menu が画面より高い時は他の AP を弱い方から減らし「N more in Settings > Wi-Fi」と出す。wayland の build は
warning 0、QEMU は T1 に依頼（結果待ち）。
