# BUG-146: Venus の guest 試験が `client=1` を前提にしていて、keiland-ime が先に起動すると全て外れる

Reproduction: reproduced（P1 / q616、main の image の Files の guest 試験が全て FAIL）
Disposition: resolved（ws099-p025、T1-039 の QEMU で PASS）
Discovery: ws127-p002 / q616（2026-10-03）。zdesktop が keiland-ime を先に起こし client 1 になるため、試験の `ZWL MAP client=1` などの期待が外れる。Files の試験 image（`plan/tools/files/config-amd64-files.mk`）から keiland-ime を外して回避した。他の WS の Venus の試験（Settings・titlebar・WS099 の C 基準など）も、IME 入りの image では同じ影響を受けうる。直し方: 試験が client の番号でなく app の名前・pid・token で窓を特定するようにする（`plan/tools/` の共有の helper）。

2026-10-03 / ws089-p010（q617、P1）: Settings の試験の image（`plan/ws089/tests/config-amd64-settings.mk`）は Files の config を include するので IME は既に無かった。
加えて Settings の試験を client の番号に頼らない形に直した（`plan/ws089/tests/settings-wait.sh` の `find_window`: `ZWL CLIENT ... ime=1` の client を除いた最後の
`ZWL MAP`）。IME 入りの確かめの image（`config-amd64-settings-ime.mk`、IME が client 1・Settings が client 2）で `settings-regress.sh` 8 本 PASS。
共有の helper（`plan/tools/`）への移しと他の WS の試験は残り（所有の外）。

2026-10-03 / ws099-p025（q645、P2）: 共有の helper `plan/tools/guest/zwl-clients.sh`（`zwl_app_clients` が `zc1`〜`zc4`、`zwl_app_client N`）を作り、

config（`plan/tools/files/config-amd64-files-ime.mk`）を足した。host の試験 PASS、QEMU は T1 に依頼（結果待ち）。Disposition は QEMU の PASS の後に resolved を提案。
