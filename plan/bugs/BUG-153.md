# BUG-153: system bar の音量の slider で 50% を click しても次の瞬間に 100% になる

Reproduction: reproduced（S1（2026-10-03、Latitude 5330、素の USB 起動、ユーザー、[結果](../ws133/s1-results.md)））
Disposition: scheduled（WS100（音量））
Discovery: 安定版 S1 の実機試験（[WS133](../ws133/ws.md)）

click で決めた値が直後の状態の通知（audiod からの返事か古い値）で上書きされている見込み。実機の HDA の範囲・変換が関わる可能性もある。まず QEMU（intel-hda）と host 試験で click の値の流れを確かめる。

## 対応（2026-10-03、q638、P1）

handling: [ws100-p010](../ws100/phase010/phase.md)。原因（読みで特定）: zdesktop の preferences の watcher が zdesktop 自身の保存（変化の 1 秒後）を
0〜2 秒後に読み戻して `volume_apply_preferences` で audiod へ送り直し、その間の新しい click（50）を古い保存値（100）で上書きしていた。
audiod・HDA・libkeiland は set した値をそのまま報告する。修正: drag 中・保存待ちの間と、自分の書き込みの読み戻し（同じ値か保存から 3 秒以内）は
適用しない。build warning 0、QEMU の `volume-bug153.sh` を T1 に依頼（結果待ち）、実機は未実施。
