# BUG-143: IME の確定のたびに 500 ms を超えて止まり、compositor が IME を迂回する

Reproduction: reproduced（P4 / q604、QEMU Venus。p005 より前から）
Disposition: tracking（WS095 の次の Phase の候補）
Discovery: ws095-p005 / q604。Enter で確定するたびに `ZWL IME bypass after_ms=500` が出て、その間の key は IME を通らず app へ直に行く。原因の見当: 確定のたびの利用者の辞書の保存（`ja-user.c` の fsync と rename）が QEMU の UFS で遅い（BUG-135 と関係の可能性）。直し方の案: 保存を key の経路の外（後回し・別 thread）へ。実機では未計測。
