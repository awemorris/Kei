# BUG-138: system bar の WiFi menu の on/off と AP への接続が未実装

Reproduction: reproduced（ユーザー、5330 実機、AX211 が動く image）
Disposition: scheduled（[ws005-p019](../ws005/phase019/phase.md)、優先度 高）
Discovery: 2026-10-02 user（5330 実機試験の後）「画面右上のWiFiメニューについて、WiFiオンオフボタンがクリックしても実装されていませんでした。個別のWiFi APを選んでもパスワード入力や接続ができませんでした。実装をお願いします。優先度高いです。」
Related: ws005-p018 の調査（利用者の join が owner の不一致で拒否される、system bar に鍵の入力が無い）。

## 調査と途中の結果（q599-i01、P1、2026-10-02）

- 原因（source と ws005-p018 の QEMU の確認）: (1) 起動の `net startup` が WiFi の方針の所有者を root にし、desktop の利用者の off と join は networkd の
  所有者の検査で EPERM。(2) system bar には鍵の入力が無かった。(3) menu を開いたときの scan が出ている間の押下は libkeiland の EBUSY で捨てられた。
- 直したこと: (2) と (3)（`userland/desktop/wayland/network.c`、phase019 の結果）。build warning 0、boot test PASS。画面と実 radio での確認は未実施。
- 残り: (1) は所有者の扱いを変える変更が auth の緩和として拒否されたため、ユーザーの明示の承認待ち（phase019 の「止めたこと」の 3 案）。
