# BUG-155: Terminal で IME の日本語を入力できない

Reproduction: reproduced（S1（2026-10-03、Latitude 5330、素の USB 起動、ユーザー、[結果](../ws133/s1-results.md)））
Disposition: resolved（ws128-p011、統合 dc7a3faca、T1-012 の QEMU で確認。実機の確認は S2、再び打てなければ reopen）
Discovery: 安定版 S1 の実機試験（[WS133](../ws133/ws.md)）

Text Editor では日本語を打てるが Terminal では打てない。Terminal が zwp_text_input_v3 に対応していない見込み。user「IME非対応なんじゃない？これは要修正。」QEMU で確認できる。

## 対応（2026-10-03、q638、P1）

handling: [ws128-p011](../ws128/phase011/phase.md)。原因は Terminal が text-input-v3 を求めず、text input の event を捨てていたこと
（zdesktop は served な text input が無いと key を IME に渡さない）。窓を開いたら text input を求め、commit を shell へ、preedit を cursor に
描く。target の build は warning 0、QEMU の試験 `plan/ws128/tests/terminal-p011-ime.sh` を T1 に依頼（結果待ち）、実機は未実施。
