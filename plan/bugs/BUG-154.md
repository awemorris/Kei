# BUG-154: WiFi の AP を切り替えるとき「Connecting...」の表示が無い

Reproduction: reproduced（S1（2026-10-03、Latitude 5330、素の USB 起動、ユーザー、[結果](../ws133/s1-results.md)））
Disposition: scheduled（WS005（system bar・Settings の WiFi、WS131 の backend の後の path））
Discovery: 安定版 S1 の実機試験（[WS133](../ws133/ws.md)）

別の AP を選んでも約 10 秒何も表示されず、その後にチェックが付く。user「これは問題なので修正が必要。Connecting...は必要。」→ system bar の menu と Settings の Wi-Fi に接続中の表示（行の spinner と「Connecting to X...」）。QEMU の network-probe（遅い join）で確認できる。

## 対応（2026-10-03、q638、P1）

handling: [ws005-p026](../ws005/phase026/phase.md)。原因（読み）: menu を開いた時の scan の間に押した join は slot で待ち、join の間も
networkd の state は前の AP のままなので、daemon の state だけを見る表示が何も変わらなかった。click から join の答えまで「Connecting to X...」と
行の「Connecting...」を出す（system bar と Settings）。target の build は warning 0、host-slot PASS、QEMU は T1 に依頼（結果待ち）、実機は未実施。
