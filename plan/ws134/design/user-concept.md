# システムモニターのデザインのコンセプト（2026-10-03 ユーザー、原文）

参考の画像: [reference-image.webp](reference-image.webp)（System Cockpit の画面）。

全体コンセプト — “Analytic Spatial UI” または “Soft Industrial Intelligence”。無機質すぎない・感情的すぎない・研究施設／制御室／設計ツールの中間・「賢そう」「整理されている」「信頼できそう」。

1. 3D は飾りではなく階層を見せるために使う。各パネルは少し浮いた薄いプレート（サマリーは手前、詳細グラフは後ろ、背景に薄い情報レイヤー、アラート時だけ対象が少し前に出る）。3D 形状は複雑にしない。ごつい金属フレームや SF 計器ではなく、薄いガラス／樹脂／セラミックの情報プレーン。
2. アニメーションは「反応」ではなく「呼吸」。常時わずかに動くが気が散らない、更新を自然に感じる、状態変化だけ少し強く動く。数値は軽くフェードとスライド、グラフはぬるっと補間、パネルはほんの少しパララックス、背景の粒子や光は非常に弱い。常に光る・スキャンライン・六角形や HUD の多用は避ける。

3D の使いどころ:
- A. 中央に「システム状態の立体コア」（半透明の立方体・多層構造体・情報結晶・球とリング）。状態で静かに変化: CPU 高 → 上層が明るく、GPU 高 → 側面の層が厚く脈動、RAM 圧迫 → 内部が密に、Network 増 → 周囲の細いラインが流れる、Disk I/O 増 → 下層のリングが回転。意味のない回転はしない（ごく微弱か操作時だけ）。
- B. CPU コア群を立体タイル面（使用率が高いほど少しせり上がる浅いレリーフ、色は明度差、高負荷時だけエッジが薄く光る、タップで拡大）。
- C. GPU は高密度モジュールカード（薄いプレート、角が少し丸い、Util＝面の充填率・VRAM＝内部スロットの満ち具合・温度＝薄い熱勾配・電力＝細いメーターライン、Util が上がるとアクティブ領域が静かに広がる）。
- D. Network と Disk は「流れ」（Network: 半透明のチューブ／ライン、RX/TX が双方向に流れ、流速で量、スパイク時だけ粒子密度が少し上がる。Disk: 読み・書きを別レーン、薄いパルス、Latency 上昇で詰まる表現、異常時だけアンバー寄り）。

Windows エコシステム風（Fluent の整頓感を借り、質感は一段未来寄り）:
- 形状: 角丸は丸すぎない、余白を広く、罫線は極細、セクションは影ではなく層の違いで。
- 質感: ガラスより「薄い乳白セラミック＋半透明樹脂」（やや曇った半透明面、内側から淡く発光、エッジはシャープ、奥行きは浅い）。
- 色: 背景は青みのダークグレー、面はチャコール〜スレート、テキストは少し青灰色、補助線は薄いシアン／アイスブルー。通常はシアン／青白／淡いミント、注意はアンバー、危険は抑えた赤橙。派手なネオンは避け、「光る」のではなく「冷たく存在する」。

アニメーションの具体案: パネルの浮遊感（1〜4px の視差、慣性）／数値は桁ごとに軽くスライド（増加は上、減少は下、前値が一瞬薄く残る）／閾値超えは段階的（エッジに薄いアンバーの輪郭 → 対象が少し前に → 関連グラフに縦のガイドライン → 重大時だけ赤系）／データフローは細い光のパルス・柔らかい帯・移動するグラデーション程度／カードをタップするとカード自体が手前にせり出して詳細に変形（周辺がやや後退、内部が分離展開、下から詳細チャート）。

既存と違うものに: 「窓」ではなく「層」で構成（1 つの空間に情報層が浮く、SF すぎない）／中央の状態コアを製品の顔に／グラフを構造体に寄せる（メモリの Used・Cache・Available・Swap を層構造のブロックに）。

タブレット: タップでカードが浮く、スワイプで時間軸変更、長押しで詳細固定、2 本指で俯瞰と詳細の切替。小さすぎる文字・密なグリッド・多数の常時回転・細かすぎる粒子や線は避ける。1 秒で理解できる 3D。

トーン: 派手ではなく端正、未来的だが誇示的ではない、工業的だが無骨すぎない、Windows 文脈だが Fluent の焼き直しではない。「高級な分析装置」「先進研究施設の観測端末」「金融端末ではないが同じくらい知的で静かな緊張感」。
