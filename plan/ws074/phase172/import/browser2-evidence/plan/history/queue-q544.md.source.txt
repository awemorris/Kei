## Exact scope / design / criteria

Document, immediately after last actual direct tbody or append. Native table and
section insertRow(optional long=-1)/deleteRow(required long) use current native
membership after exactly one WebIDL signed long conversion; receiver brand before
conversion, undefined insertion uses default -1, missing deletion TypeError,

or undefined on deletion; empty delete(-1) no-op. No calls to script-visible rows/
methods or cached snapshots. Optional conversion may mutate/adopt/remove target;
explicit root slots protect owner/argument/new row/body/parent/reference through
conversion and actual host callbacks. Current owner re-evaluated after conversion.

new tbody+tr then inserts complete body; zero rows/existing bodies appends row to
last direct tbody; -1 or length appends to parent of last logical row; other index
inserts before indexed logical row in its actual parent. Section insertion/deletion
only direct actual HTML tr; nested/foreign/uppercase excluded. Reuse native logical
iterator through internal pure bridge in collection.c; static public table getter
ownership unchanged. New bind/table-row.c registered production source list.

parent table; sectionRowIndex uses direct table logical list or direct actual
section list; otherwise -1. Native exact namespace/local case and forged receiver
rejection. Readonly indices immediately follow moves/deletion/adoption.

All allocations checked before partial new-body publication; unpublished body+row
link uses pure DOM before one checked insert/host notification of complete subtree.
Regular mutations reuse bind_insert and DOM/environment removal notifications.

Document snapshot/view. Native output survives callback removal/GC and final-root
release reclaims cycles. No raw realm/Window lifetime state stored on objects.
