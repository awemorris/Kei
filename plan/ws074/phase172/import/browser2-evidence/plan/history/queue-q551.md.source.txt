## Exact scope / design / criteria

Add internal public **bind_validate_insert(realm,parent,node,reference)** in new
bind/insertion.c registered in production libbrowser source list/internal.h. Pure
native pre-insert validity for actual ordinary node graphs, childrenToExclude
empty; no adoption/unlink/insert/generation/environment/host mutation. Caller owns
participants through potential checked DOM-exception allocation, as existing
bindings/Range temporary roots require. Invalid embedding NULL arguments EINVAL.
Actual parent must Document/Fragment/Element; incoming node cannot inclusively
contain parent; nonnull reference must actual direct child (Hierarchy ancestor
before NotFound reference). Allowed incoming Fragment/doctype/Element/Text/Comment
only among existing supported types; Document invalid. Doctype only into Document;
Text cannot enter Document; Comments are accepted.

For Document: Fragment >one direct Element or any direct Text invalid, even empty
Text; no-element/no-Text Fragment accepted. Element/one-element Fragment reject
existing Document Element, insertion before doctype or before a node with following
doctype. Doctype rejects existing doctype, reference preceded by an Element, or
append after existing Element. Actual child types/order/ordinary direct links only,
no script-visible documentElement/doctype/childNodes consulted. Empty exclusion
list intentionally preserves existing rejection of moving Document's existing
Element/doctype within itself; do not invent node-exclusion semantics. Check whole
Fragment before moving any child. Checked exception status/code3/8 and no state
change on validation failure.

bind_insert first calls helper, then keeps existing actual parent host resolution,
self-reference adjustment, checked adoption/original removal, Fragment splice and
per-node environment/host hooks/error propagation. Remove duplicate inline validity
from bind/node.c; no behavioral changes for previously valid cases except correct
new Document rejection. Helper success alone does not authorize or perform mutation.
Public JS appendChild/insertBefore inherit stronger validation. New source belongs
to existing bind layer, pure static Document helper, no DOM/VM module ownership
change. Null-pointer entry is bounded embedding validation, not a product setting.

No Range.insertNode/Textsplit/insertion/data repair yet (next finite Phase), full
replaceChild/replacement exclusions, replaceChildren/moveBefore, Shadow/custom/
Attr/PI/new node interfaces, DOM mutation observers or full DOM conformance. Existing
