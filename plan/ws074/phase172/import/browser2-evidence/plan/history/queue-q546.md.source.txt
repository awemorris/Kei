or removal affects selectedness only while clean, presence reflection independent
of owned state. Native option.defaultSelected boolean attribute getter/setter and
option.selected owned getter/setter with boolean conversion/no user callbacks;
selected setter dirties and enforces single-select exclusivity then normalizes.

conversion once after brand, root target+argument through reentrant conversion,
then clears current native list/all flags, sets selected match and only its dirtiness;
no automatic fallback after this explicit setter. Root cleanup every failure path.

subtree after links consistent, preserve actual old/new owners across pure no-GC
normalization, and normalize affected lists. Moving selected option or group gives
last selected incoming subtree member precedence in a single select. Nearest-owner
membership shared p134; nested select/blocking containers/templates unchanged.

removing multiple retains first selected. Size attribute changes normalize current
list using unsigned nonnegative parsing; default single display1/invalid fallback1,

select disabling does not disable its options. Relevant option/group disabled
attribute changes normalize; selected attr value replacement never dirties or
reselects an already present clean attribute. General attribute add/update/remove
hooks apply only actual HTML exact tag and no namespace/exact local attr name.
