no new source module/DOM ABI or exception machinery. Original string conversion
exceptions propagate before validation; throw in the callee's realm as existing
DOM methods do. No new product/major architecture decision.

namespaces, parser token validation, attributes, Traversal/Range/loading/CSSOM/
