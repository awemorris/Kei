## Exact scope / design / criteria

New xml/dom.h and xml/dom.c native C xml_document_project(heap,model,content,&created)
converts a successfully validated immutable p161 XML model into a new owning native
DOM Document. NULLout until whole projection succeeds; explicit caller content kind
XML/XHTML/SVG (HTML rejected), no MIME guessing by root or test name. Document
DOM_NO_QUIRKS/default native identity; no browsing context/view/prototype snapshots
created here. Real binding owner/window installation and actual response URL/MIME/
activation belong to later native navigation. Pure conversion does not execute
scripts, fetch PI stylesheets, synthesize events or call binding mutation hooks.

Iterative native preorder uses actual source parent/next/child edges and corresponding
native parent, no C recursion or depth truncation. Every real model Element/Text/
CDATA/Comment/PI becomes matching native type; qualified names represented by exact
local/prefix atoms and exact namespace URI strings, built-in namespace classes only
for canonical exact URIs; arbitrary namespace preserved, no HTML name/case recovery.
Attribute URI/local/prefix/value stored in actual native attribute records through
p162 exact add helper; unprefixed noNS distinct from xmlns/XML/custom attrs. Native
PI actual target/data and CDATA type preserved via p163 rooted factories. Source
C storage copied to owning VM strings/atoms or native CharacterData C buffers;
no projected object borrows model arena/input after model destruction. XML declaration
metadata remains parser-model metadata, not a made-up DOM field/API. DTD profile
already unsupported in parser; no DOM doctype or full XML metadata serialization claim.

Root slots registered NULL before any VM allocation, owning Document root/pending
unlinked native node and all temporary local/prefix/URI/value/PI target strings kept
through allocating conversions/factories. Publish complete Element names/URI before
attributes; append complete pending nodes into rooted actual tree. Every partial
registration/conversion/allocation/unsupported model-kind failure unwinds roots and
leaves NULLout; unreachable partial native graph collected normally, only C-owned
model remains caller-owned. Module registered once in libbrowser Makefile; no changes
to parser or existing DOM/binding/public APIs, source addition only plus fixture.

CDATA/PI/text/comments/default empty/custom attr/builtins/Unicode; parse thenproject,
