## Acceptance and design

- A page making over 100 finite timer/message tasks can finish within the virtual
  clock budget. A zero-delay loop still has a task bound; exhausted work is reported
  instead of silently appearing settled.
- Headless callers can explicitly choose a bounded virtual-time budget; default
  behavior remains 5000 ms. No test-specific production path.
- Unmodified pinned Acid3 is run with an explicit budget. Score, completion,
  exceptions and process status are distinct from pixel agreement. A separate
  diagnostic copy records all 100 indexed results or explicitly lists missing ones.
  Test assertions and expected answers are never modified.
- Acid2 remains exact. Plain/ASan builds, targeted timer/message regressions,
  runner verification, full review of changed source and whitespace/style pass.
- Record the missing feature groups and a bounded next Phase; no DOM API, iframe,
  HAL, toolchain, ES module, or full CSS2 implementation in this item.
