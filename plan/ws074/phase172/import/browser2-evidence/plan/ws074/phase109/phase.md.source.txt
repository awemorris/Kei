## Evidence and design before execution

frame_create currently supplies no computed_style/selector_engine callback;
computed_write returns empty and query_engine matches nothing. Existing css_engine
already handles cascade, UA sheet, inline declarations and selectors. Its style
cache contains raw DOM pointers; parsed VM strings are atoms, marked for the heap
lifetime (vm_heap_collect/atom table), not ownership edges to a child realm.
Existing css_engine/css_sheet destruction frees C storage without reading DOM
cells, so Window-owned context cleanup can obey p106 finalizer ordering.

Add bind/style-context.c and register in libbrowser/Makefile. Opaque C context
owned by Window stores an engine and parsed inline sheets. Gather connected HTML
<style> text in tree order using existing css_sheet_create/engine APIs and the
element media list. UA/inline styles and embedded @media use existing parser;
external link/@import/resource fetching remains absent. Prepare a new complete
context when Document generation changes before replacing old one; viewport
changes invalidate engine caches through existing setter. Preserve current
embedding viewport contract; no child layout/painting or box-size viewport work.

Child-only fallback: context_depth>0, managed active Window, correct owning
Document. Primary supplied host engines and empty-host behavior remain intact.
Resolve element/query root's owner through Document.view, including borrowed
parent methods. Computed lookup walks ancestor elements from root to target
using existing inheritance/cascade, with checked C buffers and output pointer
lifetime through serialization. Context release at window_release frees engine
then lent sheets/C vectors; never reads DOM/VM cells. It registers no permanent
child roots; saved declarations retain their elements through existing tracing.
Expose supported float under cssFloat using ordinary prototype accessor setup.

Affected: new binding module, internal/window/query/computed/style bindings,
libbrowser source registry, focused tests. No CSS grammar/new properties/selector
fixes, CSSStyleSheet API, URLs/navigation/parser/Traversal/Range/HAL/toolchain.
These remaining gaps get subsequent finite phases; unknown prerequisites still
end this attempt uncleared before replanning.

Apply [Guardrail](../../guardrail.md), full [C standard](../../coding-style.md),
browser design CSS/DOM/VM boundaries and inspected [CSSOM getComputedStyle](https://drafts.csswg.org/cssom/#dom-window-getcomputedstyle)
Editor Draft2026-08-31. Shared engine APIs stay unchanged; no new public libbrowser
API or agent architecture. Full changed-source standard review is required.
