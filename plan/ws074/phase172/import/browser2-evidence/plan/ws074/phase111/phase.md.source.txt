## Objective / scope / design

Indexed34 fails because :lang() is absent;38 treats zero-length text as nonempty.
Implement single nonempty CSS identifier argument :lang(C) in shared CSS parser,
class specificity, interned parameter. Match inherited nearest HTMLlang or XML
namespacedlang, XMLlang takes precedence, explicit empty overrides inheritance;
ASCII case-insensitive exact or C followed by hyphen, not arbitrary prefix.
No document HTTP/meta language exists in current engine; unprovided language
matches nothing. Existing attribute |= stays case-sensitive unless already
specified otherwise. No strings/multiple/extended wildcard language-range syntax.

:empty ignores comments and zero-length DOM_TEXT nodes but still rejects any
element (including foreign namespace) or nonempty text, including whitespace.
Mutations remain handled by existing DOMgeneration/invalidation; no ownership/API
change. Shared query and cascade paths, focused JS fixture and CSS/DOM/Acid tests.
Affected css/parser.c, css/internal.h, css/cascade.c only plus tests. No HTML
control/type/radio state, new CSS properties/media, resource/loading/Traversal/
Range/VM/HAL/toolchain. Full Guardrail/C standard/browserCSS boundaries apply.
[Selectors3 language](https://www.w3.org/TR/selectors-3/#lang-pseudo) and
[empty](https://www.w3.org/TR/selectors-3/#empty-pseudo), Recommendation2018-11-06,
read2026-10-01; historical Acid3 target uses these semantics. No full Selectors4 claim.
